## 2. 数据结构

`ScreenMaskConfig` 是不可变 `@Serializable data class`，包含：

- `enabled: Boolean = false`
- `xRatio: Float = 0.05f`、`yRatio: Float = 0.80f`
- `widthRatio: Float = 0.90f`、`heightRatio: Float = 0.15f`
- `color: Long = 0x000000`（RGB，透明度独立控制）
- `alpha: Float = 1f`（不透明度）
- `cornerRadiusDp: Float = 0f`

比例均限制在视频内，最小宽高 0.02；修复 NaN/Infinity、越界、损坏 JSON。缩放固定左上角，不会为了扩大尺寸移动区域。另有运行时 `ScreenMaskBounds` 返回视频局部像素坐标，不持久化像素。已覆盖最小矩形贴右下角时 `1f - 0.98f < 0.02f` 的浮点误差。

支持 12 种常用颜色（黑、白、灰、深灰、浅灰、米白、红、橙、黄、绿、蓝、紫），以及独立的红/绿/蓝 0–255 通道调整。每个通道用现有步进菜单调整，保持其他通道和透明度不变，色块及 #RRGGBB 实时预览，即使遮挡关闭也可调色。不透明度 0–100%、圆角 0–100dp，含底部字幕、双语字幕和自定义区域。重置恢复默认并关闭。

## 3. 图层及坐标

`VideoPlayerScreen` 根据现有 `uiState.aspectRatio.ratio`，或 `videoWidth / videoHeight`，建立居中 `Box(Modifier.aspectRatio(...))`。视频和 Mask 填满此同一容器，Media3 仍使用原来的 `RESIZE_MODE_FILL`。因此外部黑边不计入比例，手动 4:3 / 16:9 切换也使用同一基准；宽视频按可用宽高适配，不再强行固定全高。

绘制顺序：`BvVideoPlayer → ScreenMaskOverlay → DanmakuPlayerCompose → Controller 的 BottomSubtitle / 控制 UI / 菜单 → 编辑提示 → Dialog`。

正常状态遮挡不接收焦点或输入。Canvas 不读取播放进度，无轮询、额外解码、Bitmap、截图处理或逐帧偏好写入。遮挡配置独立于高频 seekerState，通过独立 StateFlow 传递。

## 4. Prefs

复用 `Prefs` 的对象映射委托和现有 Preferences DataStore，键为 `screen_mask`，全部字段编码成一个 JSON 字符串一次写入。Application 初始化 Prefs 时恢复；PlayerMenuViewModel 从 Prefs 初始化，不使用视频 ID。

编辑方向键只更新内存，返回时调用 `saveScreenMask()`；开关、预设、颜色、不透明度、圆角及重置立即经现有 Prefs 异步写入。强杀进程发生在编辑尚未结束时，未保存的草稿不保证恢复。连续调色仍沿用原来的异步写入，但事务执行时检查该任务是否已过期，防止旧任务因 IO 调度乱序覆盖新值。

## 5. TV 按键

菜单入口为播放器设置 → 画面遮挡 → 编辑遮挡区域 → 自定义。

| 状态 | 按键 | 行为 |
|---|---|---|
| 移动 | 左/右/上/下 | 对应方向移动 1% |
| 缩放 | 左/右 | 宽度减/增 1% |
| 缩放 | 上/下 | 高度减/增 1% |
| 编辑中 | 确定或菜单 | 切换移动/缩放（长按不重复切换） |
| 编辑中 | 返回 | 保存退出 |

进入时关闭控制面板、取消尚未执行的 seek；编辑层位于 Controller 外部，消费整对按键，避免方向键同时快进、确定同时暂停。退出后焦点交还 Controller。编辑显示青色边框和操作说明；关闭状态也可以预览编辑，完成编辑不自动开启。

## 8. 人工验收与风险

在 `emulator-5554` 中安装 APK，用 ADB 遥控器按键人工操作：

- 打开播放器菜单、开启遮挡、进入编辑，移动并缩放成功。
- 返回后边框消失，菜单可重新打开；核对 DataStore 中 `x=0.04, y=0.79, width=0.89, height=0.14`。
- 修改颜色为灰色后，强制停止并重启 App，进入首页另一视频，灰色遮挡位置和大小保持。
- 关闭后灰色遮挡完全消失。
- 菜单和播放错误提示绘制在遮挡上方。编辑期间未观察到方向键触发播放器快进。

`restart.png`、`disabled.png` 保存在上述报告目录。连接的物理电视未安装或修改。

播放器存在 SurfaceView 与普通 View/Compose 混合层级：当前视频 PlayerView 在下，DanmakuView 是普通 View，源码层级符合要求；Compose 像素测试验证了上层覆盖。真实视频接口在两次尝试中返回 `All codec types are failed to get play data`，因此不能把错误页面上的验证当作正常播放验收。
